# 初中函数绘图（SwiftUI）

面向初中数学学习的函数绘图 App 核心视图，使用 SwiftUI 与 Canvas，目标最低系统版本为 iOS 16。

## 当前基线

- 输入并校验常见函数表达式，例如 `y=2x+1`、`y=x^2-4`、`y=1/x`
- 表达式支持变量 `x`、括号、四则运算、幂运算，以及 `sin`、`cos`、`tan`、`abs`、`sqrt`、`exp`、`ln`、`log` 等函数
- 一次函数、正比例函数、二次函数、反比例函数示例
- 多条参考曲线叠加比较
- Canvas 坐标系、自适应网格与刻度、捏合缩放、拖动平移和视图重置
- 数值扫描零点、y 轴交点与部分二次函数顶点分析
- 可配置起点、终点、步长的函数值表
- 一次、反比例、二次函数学习说明

## 运行方式

当前仓库先迁移核心视图源码，尚不是完整的 Xcode 工程：

1. 在 Xcode 新建 iOS App（SwiftUI）工程，最低部署版本设为 iOS 16。
2. 将仓库中的 `ContentView.swift` 加入工程并替换模板视图。
3. 选择 iOS 模拟器或设备运行。

## 开发路线

按优先级推进，详见 [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md)。第一优先级是验证源码可编译、改善围绕手势焦点的缩放和坐标变换一致性；随后加强表达式安全求值、间断断线、关键点分析与自动化测试，再逐步拆分模块。
