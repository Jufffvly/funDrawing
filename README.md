# 初中函数绘图（SwiftUI）

面向初中数学学习的函数绘图 App 核心视图，使用 SwiftUI 与 Canvas，目标最低系统版本为 iOS 16。

## 当前主实现

本仓库本轮维护的主文件为 `funDraw/ContentView.swift`。根目录的 `ContentView.swift` 是另一份实现，不应直接覆盖主文件。

- 任意函数实时输入、语法校验和蓝色曲线绘制
- 独立数学模块 `funDraw/MathEngine.swift`：安全解析、数值求值、二次多项式系数提取、近似零点和函数交点搜索
- 自动识别可解析为二次多项式的顶点、对称轴和判别式
- 增加第二个任意函数输入（绿色曲线），自动搜索两函数在当前横轴可视范围内的交点，并在图中标注坐标
- 在图中标注零点、y 轴交点、二次函数顶点和对称轴
- 自动显示当前 x 轴可视范围内检测到的零点，并在图中标记零点；若 x=0 在定义域内则显示并标记 y 轴交点
- XCTest 用例源文件位于 `funDrawTests/MathEngineTests.swift`，覆盖表达式正例/非法输入、运算优先级、定义域边界、二次函数顶点、重根及切触交点
- 支持变量 `x`、常量 `pi` / `e`、括号、加减乘除、幂运算
- 支持隐式乘法，例如 `2x`、`3(x+1)`、`2sin(x)`
- 支持 `sin`、`cos`、`tan`、`abs`、`sqrt`、`exp`、`ln`、`log`
- 常见形式示例：`y=2x+1`、`y=x^2-4`、`y=1/x`、`y=sin(x)`
- 多种内置函数曲线、参数调节、显示开关与动画
- Canvas 坐标系、自适应网格与刻度、捏合缩放和视图重置
- 采样无效值时断开曲线；相邻采样出现较大跳变时重新开始路径，避免部分渐近线附近的错误连线

## 关键点分析说明

零点和两函数交点通过区间采样、变号二分法和局部最小值细化进行数值近似；因此只分析当前 x 轴可视范围，结果标记为近似值。局部极小值细化可以尝试发现不变号的重根/切触交点，但仍不能保证找出高频、极窄根间隔或复杂奇异点附近的所有根。二次函数顶点与对称轴仅在表达式可化简为二次多项式时提供；y 轴交点使用直接求值 `f(0)`，若定义域不包含 0 则明确显示无交点。

## 表达式说明

解析器仅接受明确支持的数学运算符、常量和函数，不执行任意 Swift 代码。除以零、对负数开平方、非有限计算结果或不支持的语法会被视为无效采样；输入表达式无法解析时会显示提示，且不会绘制自定义曲线。

数值采样的跳变检测属于启发式保护，并不能保证识别所有不连续点。

## 运行方式

当前仓库尚不是完整的 Xcode 工程：

1. 在 Xcode 新建 iOS App（SwiftUI）工程，最低部署版本设为 iOS 16。
2. 将 `funDraw/ContentView.swift` 加入工程并替换模板视图。
3. 选择 iOS 模拟器或设备运行。
